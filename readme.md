# 🎵Sonic-Pulse : Collaborative Music Streamer

A web application where users can submit **YouTube URLs** to add songs to a shared **streaming queue**. The queue is **community-driven**: songs are played based on **upvotes** — the more upvotes a song has, the sooner it plays!

## 🚀 Features

- ✅ **Submit YouTube Songs** — Add songs to the queue via valid YouTube video URLs.
- 🔼 **Upvote System** — Songs can be upvoted; the highest-voted song plays next.
- ▶️ **Auto Playback** — The currently playing song updates automatically when one ends.
- 🧑‍🤝‍🧑 **Multi-user Support** — Built with session-based user authentication.

- 📱 **Mobile Responsive** — Works on phones, tablets, and desktops.
